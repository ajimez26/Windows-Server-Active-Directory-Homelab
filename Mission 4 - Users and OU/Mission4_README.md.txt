# Mission 4 – Active Directory Organizational Units and User Management

## Objective

Build the organizational structure for a Windows Active Directory environment and create the first domain user account.

---

## Environment

- Host OS: Windows 11
- Hypervisor: Oracle VirtualBox 7.1
- Guest OS: Windows Server 2025
- Domain: jimeneztech.local

---

## Tasks Completed

- Installed and configured Active Directory Domain Services
- Promoted the server to a Domain Controller
- Created the "Jimenez Technologies" Organizational Unit
- Created department Organizational Units:
  - IT
  - Human Resources
  - Finance
  - Sales
  - Marketing
  - Management
  - Workstations
  - Servers
- Created the first domain user:
  - David Rodriguez
  - Username: drodriguez

## Skills Demonstrated

- Active Directory Users and Computers
- Organizational Unit management
- User account creation
- Active Directory administration

## What I Learned

Organizational Units allow administrators to organize users and computers into logical departments. This makes administration easier and allows security policies and Group Policies to be applied to specific groups of users or computers instead of managing each object individually.
