# Mission 1 — VirtualBox & Virtualization

## Objective

Build the virtualization foundation for the Windows enterprise homelab.

## Environment

- Oracle VirtualBox
- Windows Server 2025
- Windows 11 Enterprise
- NAT Networking
- Host-Only Networking

## Tasks Completed

- Installed and configured Oracle VirtualBox.
- Created the virtual machines used throughout the homelab.
- Allocated virtual CPU, memory, and storage resources.
- Configured NAT networking for Internet connectivity.
- Configured Host-Only networking for internal communication between lab systems.
- Established the virtualization foundation used for the Active Directory environment.

## Skills Demonstrated

- Virtual machine deployment
- Virtual hardware configuration
- NAT networking
- Host-Only networking
- Resource allocation
- Virtualization troubleshooting

## What I Learned

This mission established the difference between virtualization and the services running inside a virtual machine. I also learned how separate virtual network adapters can be used for different purposes, including Internet connectivity and isolated internal communication.

## Mission Summary

Successfully created the virtualized infrastructure required to build the Windows Server and Active Directory homelab.
