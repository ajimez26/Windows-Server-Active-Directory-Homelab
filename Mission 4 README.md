# Mission 4 — Users & Organizational Units

## Objective

Build and organize the Active Directory user structure for the `jimeneztech.local` domain using Organizational Units (OUs), user accounts, and security groups.

## Environment & Tools

- Windows Server 2025
- Active Directory Domain Services
- Active Directory Users and Computers (ADUC)
- Domain: `jimeneztech.local`

## Tasks Completed

- Created Organizational Units to organize domain objects.
- Created and managed Active Directory user accounts.
- Created departmental security groups for IT, HR, Sales, Finance, Marketing, and Operations.
- Added users to appropriate security groups based on departmental access requirements.
- Practiced adding and removing group membership for temporary access scenarios.
- Distinguished between Organizational Units and security groups when managing users and access.

## Skills Demonstrated

- Active Directory user administration
- Organizational Unit management
- Security group management
- Group membership administration
- Identity and access management fundamentals
- Authentication vs. authorization
- Role-based/group-based access concepts

## Key Concept

Organizational Units and security groups serve different purposes:

- **OUs** organize Active Directory objects and can be used for administrative organization and Group Policy targeting.
- **Security groups** are used to assign permissions and control access to resources.

## Mission Summary

This mission established the user and group structure used throughout the rest of the homelab. It provided hands-on experience creating and organizing Active Directory identities and using security-group membership as the foundation for controlling access to organizational resources.
